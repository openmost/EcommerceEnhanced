# Ecommerce Enhanced

## Description

Enhanced ecommerce analytics for Matomo, built on top of the native Matomo ecommerce: GA4 dataLayer auto-mapping, brands, variants, item lists, promotions, coupons, refunds, checkout steps and shopping behavior funnels.

Work in progress. Deactivating the plugin always falls back to the native Matomo ecommerce.
